# Tidewater

Tidewater is an invented ferry timetable service. This folder is a small synthetic corpus for BreakWall's tests and quickstart; nothing in it describes a real system.

Start with the [architecture](docs/architecture.md), then the current [ingest design](docs/ingest-v2.md) and the [operations guide](docs/operations.md).

## Layout

Reference docs live under `docs/`, architecture decision records under `decisions/`, and meeting notes under `notes/`.
